# Bank Management System - C++

A console-based Bank Management System developed using C++.
The project simulates a real banking environment with client management, user authentication, role-based permissions, and transaction processing.

## Features

* User Login System
* Role-Based Permissions
* Client Management (Add, Update, Delete, Find)
* User Management
* Deposit & Withdraw Operations
* Total Balances شاشة
* File Handling باستخدام Text Files
* Structured Console Menus
* Data Persistence

## Technologies Used

* C++
* File Handling
* Structs
* Enums
* Vectors
* Bitwise Permissions
* Modular Programming

## Project Structure

The system is divided into multiple modules:

* Clients Management
* Users Management
* Transactions
* Authentication & Permissions
* File Storage System
